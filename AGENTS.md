# Third Eye Project Rules

- Keep shared website navigation, footer, and destination buttons in a browser-safe module so every product page uses consistent chrome.
- Treat this as a promotional desktop-product website, not an embedded IDE; showcase media must not imply live code execution.
- Centralize download, account, and contact destinations in a typed configuration; absent destinations show an honest availability dialog rather than fake downloads or authentication.
- Serve concept screenshots and the product video through local assets, keeping product media distinct from the landing portrait.
