# Third Eye IDE

Official promotional website and platform for Third Eye — an agentic coding IDE.

## Architecture

This project is organized into two main workspaces:
- **`frontend/`**: TanStack Start + React 19 + Vite + Tailwind CSS web application.
- **`backend/`**: Node.js / Express API server.

## Getting Started

### Prerequisites
- Node.js (v20+ recommended)
- npm

### Installation & Running

#### Frontend
```sh
cd frontend
npm install
npm run dev
```
The frontend will start on `http://localhost:3000` (or `http://localhost:5173`).

#### Backend
```sh
cd backend
npm install
npm run dev
```
The backend will start on `http://localhost:5000`.

#### Running both from Root
```sh
npm run dev
```
